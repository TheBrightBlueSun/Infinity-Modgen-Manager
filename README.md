# Credits

## Infinity Modgen Manager

**Created and developed by TheBrightBlueSun**

Infinity Modgen Manager is an independent mod-management project designed for games built on the Infinity Engine framework.

### Development

* **TheBrightBlueSun** — Project development, programming, UI, mod-management system, game detection, PAK management, runtime integration, testing, and documentation.

### Third-Party Components

Infinity Modgen Manager includes and/or integrates with third-party software and libraries. Their respective authors and licences remain acknowledged and respected.

* **CUE4Parse** — Unreal Engine asset parsing
* **SharpCompress** — Archive and compression support
* **UE4SS** — Unreal Engine modding/runtime framework
* **Rust** — Runtime shim components

Please refer to the individual component licences and included licence files for their respective terms.
